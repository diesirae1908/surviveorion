# ORION creator kit

*Assembled 2026-08-26. One self-contained folder to drag into CapCut, Eklipse, Higgsfield,
or any editor. Files are COPIES on purpose; originals live in `brand/orion/assets/` and
`reports/orion-social-v2/`. If the brand changes, regenerate this folder.*

## What's in here

| Folder | Contents | Use |
|---|---|---|
| `logos/` | Patrol Sight mark 512, wordmark, horizontal + stacked logos, app icon | Watermark corner, end cards, avatars |
| `fonts/` | Rajdhani-Bold (brand), Anton (meme captions) | Install both on the Mac once, then every editor has them |
| `colors/` | Palette PNG + `colors.txt` hexes | Paste hexes into text/shape colors |
| `copy/` | `TAGLINES.md` (one-liners by format), `COPY-BANK.md` (bios, CTAs, descriptions) | Text layers, captions, post descriptions |
| `memes/` | 18 transparent overlays (wasted, he-knew, red-circle, skill-issue, vignette...) | Drag onto video as stickers. See `memes/LICENSE.md` |
| `vo/` | "he knew" ElevenLabs takes x2 | The freeze-moment voice |
| `audio/` | victory-fanfare.wav, celebration-funk.wav (both ours, no license risk) | Fallback endings when no trending sound fits |
| `boards/` | NEW BEST score board (day 43 reference) | Fresh boards per run: template in `reports/orion-social-v2/presets/` |
| `covers/` | YouTube thumbnail 1280x720 + vertical cover 1080x1920 templates | Thumbnails; swap the {{TOKEN}} text |

## What only you can produce

1. **Run recordings + sidecar JSON** (the in-game recorder). Record every session; the kit
   turns any run into a post.
2. **Trending sounds**: added inside TikTok/IG/CapCut at edit or publish time, never baked
   from files.

## Quickstart (first CapCut test, ~20 min)

1. Install both fonts from `fonts/` (double-click, Install).
2. Open CapCut desktop, new 9:16 project, import the day 43 clip + this folder.
3. Follow `CAPCUT-TEMPLATES.md` format 1 (WASTED). Save it as a template when happy;
   every future WASTED is then a clip swap.
